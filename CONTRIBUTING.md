# Contributing

## Branches
`main` is the only permanent, protected branch. Work on `feature/*`, `bugfix/*`, `hotfix/*`, `release/*`, `experiment/*`, `research/*`. No direct pushes to main.

## Commits
Conventional, small, one story each: `feat(scope): …`, `fix(scope): …`, `docs(scope): …`, `perf(scope): …`. Signed commits recommended; linear history required.

## Pull requests
Every PR states: Problem · Solution · Tradeoffs · Testing · Security · Performance · Rollback · Docs-updated. CI must be green + reviewed before merge.
