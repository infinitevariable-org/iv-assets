# Architecture — iv-assets

This repository has **no build system and no runtime**. It is a versioned store of Infinite Variable brand and identity assets (logo/symbol marks, imagery) used across the iVPL estate.

## Components
- Binary/static asset files, tracked in git.
- Consumed by other repositories by reference/download; nothing executes here.
